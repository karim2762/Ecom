## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/karim2762/Ecom.git
```

### Navigate to Project

```bash
cd Ecom
```

### Run Locally

Simply open:

```bash
index.html
```

in your browser.

No installation required.
